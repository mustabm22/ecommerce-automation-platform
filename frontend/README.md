# منصة التجارة الإلكترونية المتكاملة

## 🌐 تطبيق الويب (React)

### المتطلبات
- Node.js و npm
- متصفح حديث

### التثبيت

```bash
cd frontend
npm install
```

### التشغيل

#### وضع التطوير
```bash
npm start
```

#### بناء الإنتاج
```bash
npm run build
```

### الميزات

✅ عرض المنتجات مع التصفية والبحث
✅ سلة التسوق المتقدمة
✅ خطوات الدفع بسهولة
✅ تطبيق Stripe و PayPal
✅ لوحة تحكم المستخدم
✅ تتبع الطلبات
✅ واجهة مستخدم سهلة

### الشاشات الرئيسية

1. **الرئيسية** - عرض المنتجات المتاحة
2. **تفاصيل المنتج** - معلومات مفصلة عن المنتج
3. **السلة** - إدارة العناصر والأسعار
4. **الدفع** - اختيار طريقة الدفع والعنوان
5. **تسجيل الدخول/التسجيل** - حساب المستخدم
6. **لوحة التحكم** - معلومات المستخدم والطلبات
