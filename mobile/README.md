# منصة التجارة الإلكترونية المتكاملة

## 📱 التطبيق الموبايل (React Native)

### المتطلبات
- Node.js و npm
- Expo CLI
- جهاز أو محاكي Android/iOS

### التثبيت

```bash
cd mobile
npm install
```

### التشغيل

#### على Android
```bash
npm run android
```

#### على iOS
```bash
npm run ios
```

#### باستخدام Expo
```bash
npm start
```

### الميزات

✅ تصفح المنتجات
✅ إضافة إلى السلة
✅ الدفع عبر Stripe و PayPal والمحفظة الرقمية
✅ تتبع الطلبات
✅ ملف المستخدم الشخصي
✅ إدارة الحساب

### الشاشات الرئيسية

1. **الرئيسية** - عرض المنتجات
2. **السلة** - إدارة عناصر السلة
3. **الدفع** - إتمام عملية الشراء
4. **المستخدم** - المعلومات الشخصية
